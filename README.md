# Orçamento e Pedido (Tkinter)

Aplicação desktop em Python/Tkinter para cálculo de orçamento e geração de tela de **Pedido / Romaneio de Materiais**.

## O que foi incluído

- Botão **Pedido** no HUD principal (parte superior).
- Campo manual de **P.I** (valor disponível da obra) com ação para **fixar P.I por obra**.
- Cálculo de orçamento (serviço + materiais + transporte).
- Cálculo de saldo do P.I: `Saldo = P.I da obra - Valor do orçamento`.
- Tela de **romaneio** com template textual e lista de materiais selecionados.

## Executar

```bash
python3 app_tkinter.py
```
